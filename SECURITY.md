# Security reporting

Browser Core is a proprietary, invitation-only technical beta. Send security reports privately via https://t.me/OpsTetherBot?start=browsercore and state Browser Core in the subject.

Do not post passwords, cookies, access tokens, private pages, or account details in public GitHub issues. Do not attempt to access another user's data while testing.

No SOC 2, ISO, independent penetration-test or uptime certification is claimed.
