# Getting started (invitation-only preview)

## Request access
Contact https://t.me/OpsTetherBot?start=browsercore. The service does not have a public self-signup form yet.

## Connect to ChatGPT
Use the MCP endpoint https://m2g.pro/browser-core/mcp with OAuth authorization. An account invitation must be approved; adding the endpoint alone does not grant access.

## Local Mac
1. Download BrowserCore-Mac-OneClick-0.7.8-beta.zip from the website.
2. Requires macOS and Python 3.10–3.13. The beta is not signed or notarized.
3. Install and pair the local agent with your own code.
4. Open Chrome extensions and allow Browser Core for the specific tab.
5. Keep your own Chrome window open when login, password, 2FA or CAPTCHA is needed.

## Your own Linux server
The BYO worker runs Chromium on a personal Linux server with an authenticated outbound connection. Initial provisioning is assisted during the private beta, not a publicly self-service package.

Manual remote control is a temporary aid for login and verification, not a replacement for working in a normal local browser. Press Done to hand control back to the agent.

Never send passwords, OTPs, cookies, API keys or recovery codes to ChatGPT messages or support.
