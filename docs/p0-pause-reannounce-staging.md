# Confirmed pause after a grant refresh — unreleased P0, 25 November 2026

Browser Core connects Chrome tabs you explicitly authorize to ChatGPT or Claude for actions on websites. For example, if you ask the assistant to prepare a supplier order and then pause the shared tab to review the draft, a queued fill must not run after the pause is acknowledged. Use the Browser Core popup to share only the required tab and pause it before taking over. Reading or drafting is not submission.

**Staging only:** local branch `p0-pause-reannounce-0740`, base `2d6b3de`, code `1558c2e950317af989e94eaf0b21fa9ba35675a8`. A same-scope native grant refresh replaces a Python dictionary while a pause is awaiting a response. Previously the acknowledgement modified the obsolete dictionary; the live root could still appear unpaused and a queued fill could be dispatched to the extension. The correction updates the live entry only after the existing original-grant scope check. A replaced grant remains uncertain, not paused by an old response. No new permission or automatic retry. An already dispatched operation may still finish; the real extension also independently checks permission and pause. This is not evidence of an actual unauthorized website write.
